# Mon bilan du Bootcamp GoMyCode

Ce document fait le point sur mon parcours au sein du Bootcamp développement web (pile MERN) de GoMyCode : ce que j'ai appris, où j'en suis aujourd'hui et le développeur que je veux devenir.

## Suis-je prêt pour une nouvelle étape professionnelle ?

Oui. J'ai terminé l'ensemble des checkpoints de la formation et je passe maintenant à la phase de laboratoire avec un vrai projet : le site e-commerce de ma boutique, Horizon Luxe Shop by DJA.

Je ne prétends pas tout connaître. Mais je sais désormais partir d'une page blanche, construire une application complète, la mettre en ligne et la corriger quand elle ne fonctionne pas. C'est cette autonomie qui me fait dire que je suis prêt à travailler sur de vrais projets, pour de vrais utilisateurs.

## Le développeur que je veux être

- **Un développeur qui ne dit pas « non, je ne connais pas cette technologie ».** Face à un outil nouveau, ma réponse sera : « je ne le connais pas encore, je vais l'apprendre ». Le Bootcamp m'a montré que tout s'apprend avec de la documentation, de la pratique et de la persévérance.
- **Un développeur capable d'improviser.** Les projets ne se déroulent jamais comme prévu. Je veux savoir m'adapter, trouver une autre solution quand la première est bloquée, et avancer quand même.
- **Un développeur qui code et qui corrige ses erreurs.** Une erreur n'est pas un échec, c'est une information. J'ai appris à lire un message d'erreur, à chercher sa cause et à la corriger au lieu de la contourner.
- **Un développeur qui sécurise ce qu'il construit.** Un site qui fonctionne ne suffit pas : il doit protéger les données de ceux qui l'utilisent. Je veux que la sécurité fasse partie de mon travail dès la première ligne de code.
- **Un développeur dont les utilisateurs sont contents.** Ma plus grande motivation est de voir des personnes utiliser mes applications avec satisfaction. Le code n'est pas une fin en soi : il doit rendre service à quelqu'un.

## Les compétences acquises pendant le Bootcamp

| Domaine | Ce que je sais faire |
|---|---|
| Front-end | Construire des interfaces avec React : composants, état, formulaires, appels à une API |
| Back-end | Créer une API avec Node.js et Express : routes, traitement des requêtes, logique serveur |
| Base de données | Modéliser et manipuler des données avec MongoDB, Mongoose et MongoDB Atlas |
| Outils | Versionner mon code avec Git et le publier sur GitHub |
| Déploiement | Préparer une application pour la production : variables d'environnement, build du front-end, hébergement dans le cloud |
| Méthode | Découper un problème en étapes, tester en local, lire les erreurs et les corriger |

Au-delà de la technique, j'ai surtout appris à apprendre : chercher l'information, comprendre avant d'exécuter, et ne pas abandonner devant un blocage.

## Ce que je retiens

Le Bootcamp m'a fait passer de « je suis des tutoriels » à « je construis mes propres applications ». Chaque checkpoint m'a confronté à des erreurs, et c'est en les résolvant que j'ai le plus progressé.

## La suite

- Réaliser et mettre en ligne mon projet final : le site e-commerce de Horizon Luxe Shop by DJA.
- Approfondir la sécurité des applications web.
- Continuer à apprendre de nouvelles technologies, projet après projet.

Merci à mon instructeur et à toute l'équipe GoMyCode pour l'accompagnement tout au long de ce parcours.
